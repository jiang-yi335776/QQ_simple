## 🛠️ 安装说明

你需要先安装 Visual Studio 2022。

1. 克隆项目
git clone https://github.com/jiang-yi335776/QQ_simple.git

2. 安装依赖 
在Visual Studio扩展中下载QT VS tools 插件

## 🚀 如何使用

1.在Visual Studio打开本地解决方案，QtQQ.sln文件

2.将Resources中的图片添加到CCMainWindow.qrc文件中
